### Day 5 — Wider hidden-required-option-group bug

Day 2's smoke test (2026-09-11) confirmed the known Costa-Vida-"Single Taco" bug is wider
than thought — Wingstop's Cajun Fried Corn and Veggie Sticks hit it too. Both `itemPage`'s
`optionLists` (HTTP fast path) and the Playwright DOM extraction report only the FIRST
required group; `addCartItemV2` then rejects on a second, never-surfaced group ("Corn
Seasoning Options" / "Modify Veggie Sticks"). Suggested fix (not yet done, now confirmed
general-purpose, not Costa-Vida-specific): on `item_validation_error`, parse the named group
out of the API error response and re-surface it as an additional required group so the user
gets asked for it instead of a bare rejection.
